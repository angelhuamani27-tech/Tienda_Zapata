# Plan vigente

1. Mantener una web Next.js de catálogo sin cuentas ni almacenamiento de pedidos.
2. Mostrar las 30 imágenes recibidas con nombres, descripciones y precios de ejemplo, identificados como datos de una demo académica.
3. Usar un diseño centrado en las fotos, con encabezado corto, catálogo cercano al inicio y ficha individual.
4. Guardar altas y bajas locales en IndexedDB; no ofrecer una API de escritura pública sin autenticación.
5. Guardar el carrito en este navegador y generar un mensaje de WhatsApp con cantidades y total. Añadir el enlace público de modelos iniciales cuando exista dominio.
6. Comprobar compilación, persistencia local, vistas móvil/escritorio, imágenes y enlaces antes de publicar cambios.
